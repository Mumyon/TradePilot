# TradePilot AI 피드백 비교 설계

## 앱의 두 단계

| 단계 | 실제 시세 기반 모의투자 | 과거 장세 ChatGPT ON |
| --- | --- | --- |
| 1. 시세 분석 | 차트에서 **1단계 · AI 시세 분석**을 누르면 현재 체결가와 기준 시각을 바탕으로 ChatGPT가 최근 1년의 공개 자료를 검색한다. | 현재 가상 시점에 공개된 최근 최대 35개의 완료 5분봉을 해석한다. 외부 검색은 사용하지 않는다. |
| 2. 주문 조언 | 매수·매도 확인 창에서 현재 시세, 방향, 지정가를 다시 검토한다. 해당 계정·종목의 최근 10분 내 완료된 시세 분석이 있으면 활용한다. 첫 분석이 없으면 웹 자료를 참고해 바로 주문을 검토한다. | 같은 봉의 시세 분석을 확인한 뒤 주문 방향, 지정가·수량, 사전 계획을 검토한다. 조언을 확인하고 진행·보류를 직접 선택한다. |

실제 시세 화면에서는 별도 투자 기간이나 성향을 입력하지 않는다. 과거 장세의 AI 요청에는 종목 식별자와 실제 날짜를 넣지 않는다. 서버는 차트가 공개한 범위에서 시계열을 잘라 제공하며, 그 뒤의 봉은 체결과 사후 평가에 사용한다.

## ON/OFF 비교

**모의투자 → 과거 장세 연습 → 사례의 AI 피드백 비교 시작**에서 시작한다. 첫 조건의 순서는 기본적으로 서버가 무작위로 배정한다. 첫 실행을 종료하면 **같은 조건 · 반대 ChatGPT**로 짝을 만들 수 있다.

| 조건 | 주문 전 제공 정보 |
| --- | --- |
| ChatGPT ON | 공개 시세와 두 단계의 ChatGPT 피드백 |
| ChatGPT OFF | 동일한 공개 시세와 주문 요약 |

두 실행에는 같은 사례, 시작 시점, 초기 자금, 사전 계획, 주문 제한, 수수료, 다음 봉 시가를 이용한 체결 규칙을 적용한다. 규칙 기반 행동 경고와 기존 1시간 예측은 두 조건에서 숨긴다. 결과 화면에서 같은 쌍을 함께 표시한다. 마지막 봉까지 진행하지 않은 실행에는 미완주를 표시한다.

시세 분석 확인과 주문 조언 확인은 별도 이벤트로 기록한다. ON에서 응답이 실패하거나 화면을 닫으면 접수할 수 없고, 조언 미확인 점검으로 구분한다. 두 조건 모두 주문 진행 또는 보류 시 판단 근거를 선택적으로 적을 수 있다. CSV에는 조건과 점검별 조언 확인 시각을, JSON에는 확인 이벤트와 모델·응답 상태·본문을 포함한다.

## 효과를 평가할 때

주지표 후보는 **위험 신호가 잡힌 접수 가능 주문 점검 중 실제 접수한 비율**이다. 분모가 0이면 평가 없음으로 표시한다. 위험 신호는 양쪽에 동일한 규칙으로 계산하는 행동 지표다. 보류 횟수, 계획 준수, 판단 근거, 체결, 수익률과 최대 낙폭은 함께 보되 각각 의미를 구분한다.

주문 조언의 대기 시간은 서버가 AI 작업을 접수한 시점부터 앱의 첫 표시가 서버에 기록될 때까지다. 응답 조회와 통신 지연도 포함된다. 판단 시간은 ON에서 조언, OFF에서 주문 요약이 처음 표시된 시점부터 진행·보류를 선택할 때까지다. 닫기·만료와 표시 시각이 없는 점검에는 판단 시간을 부여하지 않는다. 주문 점검 종료 시점의 AI 상태를 고정해서 작업 실패, 대기 중 종료, 요청 기록 없음과 기존 미측정을 구분한다. 기록은 시선 추적이나 답변 숙독 여부를 측정하지 않는다.

연구 JSON을 두 실행에서 각각 저장한 뒤 `server` 폴더에서 아래처럼 집계한다. 같은 사례의 두 실행을 묶어 ON−OFF 차이를 계산한다. ChatGPT 실험은 두 실행 모두 마지막 봉에 도달한 쌍을 집계하고, 규칙 기반 Pilot 실험과 별도로 표시한다. 분모가 없는 접수율과 표시 기록이 없는 판단 시간은 비워 둔다.

```sh
PYTHONPATH=. .venv/bin/python tool/replay_pair_summary.py on.json off.json --output pairs.json
```

실험 전에 주지표와 탈락 기준을 확정하고, 여러 참여자와 상승·하락·횡보 사례를 확보한다. 순서를 참가자 간에 균형 있게 배정하고, 동일 장세를 다시 봐서 생기는 학습 효과를 기록한다. 실제 사례의 이름이나 결말을 미리 아는 문제를 줄이려면 참여자에게 사례를 익명으로 제시한다. 모델과 프롬프트 버전도 고정한다.

이 설계로 두 단계 전체의 효과를 비교할 수 있다. 각 단계의 기여를 따로 측정하려면 후속 실험에 **시세 분석만 제공**하는 조건을 추가한다. 사람이 참여하는 본 실험 전에는 동의, 익명화, 자료 보존 범위도 정한다.

## 검증 결과

- 서버 테스트 39개에서 조건 고정, 같은 비교 키, 미래 봉 제외, OFF AI 호출 차단, ON의 두 단계 확인, 주문과 로그 내보내기를 검증했다.
- Flutter 테스트 22개에서 ON과 OFF의 팝업 흐름과 기존 주문 화면을 검증했다.
- 실제 ChatGPT 연결에서 합성 5분봉의 시세 분석과 매도 조언 응답을 각각 검증했다. iPhone 시뮬레이터에서도 삼성전자 웹 검색 보고서와 이를 활용한 주문 조언이 재시도 후 표시됐다. 모의 주문 접수와 체결은 격리 테스트에서 확인했다.
