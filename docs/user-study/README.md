# 사용자 시연 평가

현재 응답자는 0명입니다. 실제 사람의 응답만 `responses.csv`에 입력합니다. 이름/이메일 대신 임의 참여자 번호를 사용합니다. 같은 사람이 여러 번 평가한 결과를 별도 인원으로 세지 않습니다.

## 10분 진행 순서

1. 앱에서 계정 생성 및 로그인. 테스트 시세와 실제 시세의 차이를 설명할 수 있는지 확인.
2. 관심종목 선택 → 차트의 기준 시각·거래량 확인 → AI 분석 대기 이유 확인.
3. 계좌 관리에서 위험한도와 가격 범위를 가진 매매 계획 등록.
4. 매수 1주 점검 → 이유 및 주문 요약 확인 → 접수와 체결의 차이 확인.
5. 같은 방향 재주문 시 쿨다운 차단을 확인. Pilot OFF로도 위험 규칙이 유지되는지 확인.
6. 일지에서 당시 계획/경고와 실제 체결 조회, 복기 메모 작성.

행동 경고 상황은 검증 보고서의 합성 시나리오임을 설명합니다. 시연을 위해 실제 학습 모델이나 수익률이 있는 것처럼 설명하지 않습니다.

## 질문 (각 1~5점)

- 경고 이유와 위험 규칙의 차이를 이해하기 쉬웠나요? (`clarity_rating`)
- 주문과 거래 복기를 수행하기 쉬웠나요? (`ease_rating`)
- 핵심 기능에 전반적으로 만족하나요? (`overall_rating`)
- 가장 헷갈리거나 불편했던 점은 무엇인가요? (`comment`, 선택)

`completed_core_flow`는 핵심 흐름 수행 시 `yes`, 미완료 시 `no`입니다. 목표: 실제 참여자 10명 이상, 전반 만족도 평균 4.0 이상. 미달 결과도 그대로 보고합니다.

집계 (프로젝트 루트):

```sh
server/.venv/bin/python server/tool/survey_summary.py docs/user-study/responses.csv
```
