# ChatGPT 직접 검색 방식으로 변경

2026-11-09. 이전의 서버 일봉 수집·지표 계산 방식은 이 문서의 방식으로 대체했습니다.

## 현재 동작

차트 → 매수/매도 → 주문 확인 팝업 → ChatGPT가 최근 1년 자료를 직접 웹 검색 → 분석 보고서와 인용 링크 표시 → 사용자가 최종 모의주문 여부 결정.

- 투자 예정 기간·투자 성향 선택란과 기본값을 제거했습니다. 요청 데이터와 프롬프트에서도 임의의 스윙·중립적 가정을 제거했습니다.
- 주문 분석을 위한 서버의 최근 1년 일봉 조회·캐시·지표 계산 코드를 제거했습니다. 서버가 주가 원본을 내려받아 ChatGPT에 전달하지 않습니다.
- 기존 주문 분석 기록 3건에 들어 있던 원본 종목·지수 일봉 배열도 정리했습니다. 모의계좌, 거래 기록, 차트용 시세와 연구 데이터는 건드리지 않았습니다.
- 요청에는 종목명·티커, 매수/매도 방향, 요청 시점과 최근 1년 검색 범위, 앱의 최근 체결가·기준 시각만 담습니다. 투자 기간·성향이나 계좌 잔고·개인 거래 이력은 보내지 않습니다.
- ChatGPT의 웹 검색 결과를 마크다운 보고서로 표시합니다. 실제 응답 스트림에서 확인된 인용은 클릭 가능한 출처 링크로 바꿉니다. 페이지 원문이나 연간 OHLCV를 로컬 DB에 저장하지 않으며, 최종 분석 답변과 출처 URL·검색 횟수는 분석 기록으로 남깁니다.
- 뒤로가기와 주문 입력 보존은 유지합니다. 분석 중·실패·만료 시 최종 접수를 막으며, 웹 검색 미지원 시 다른 유료 API나 로컬 데이터 수집으로 자동 전환하지 않습니다.

## 프롬프트

사용자가 제공한 정량 분석 프롬프트에서 기간·성향 입력을 제거하고, 최근 1년 자료의 직접 검색·공식 출처 우선·누락과 미계산 명시 규칙을 추가했습니다. 실제 전송하는 지침은 `server/app/prompts/quant_entry_ko.txt`에 모았습니다.

프롬프트만으로 검색 권한이 생기지는 않으므로 Responses API에 `web_search` 도구도 활성화합니다. 선택된 모델·계정 정책이 허용해야 하며, 응답에 완료된 검색 호출이 있는지 검사합니다. [OpenAI 웹 검색 문서](https://developers.openai.com/api/docs/guides/tools-web-search), [ChatGPT 구독 연결의 지원 범위](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations).

- 서버 관련 검사 57개 통과. 실제 검색 없이 최신 자료를 확인했다고 처리하지 않는지, 원본 일봉을 수집하지 않는지, 인용 링크 변환과 스트림 완료 검증을 포함합니다.
- Flutter 검사 9개 통과. 선택란 제거, 자동 시작, 보고서 표시, 뒤로가기, 분석 실패·만료 시 접수 차단을 확인했습니다. 정적 분석 문제 없음.
- 실제 연결된 `gpt-6-sol`로 삼성전자 분석 성공. **웹 검색 6회, 응답 약 82.2초.** 격리된 테스트 DB에서 수행했으며 주문은 접수하지 않았습니다.
- 보고서는 실제로 확보한 일부 시점의 자료와 1년 전체 시계열의 계산을 구분했고, 미계산 지표와 통계 표본 부족을 명시했습니다. 최종 판단은 **데이터 부족**이었습니다. 전문은 [실제 웹 검색 응답](QUANT_WEB_RESPONSE_2026-11-09.md)에 있습니다.
- 2026-11-12, 로그인된 iPhone 17 시뮬레이터에서 삼성전자 모의 매수 확인 팝업을 열었습니다. 투자 예정 기간·투자 성향 선택란이 없고, 자동 분석 후 ‘웹 검색 5회 완료’와 보고서의 출처 링크가 표시됐습니다. 정규장 종료로 접수 버튼은 비활성화됐으며, 주문을 제출하지 않았습니다.

## 데이터 범위

‘최근 1년 자료를 검색하도록 요청했다’와 ‘1년 전체 일봉을 확보해 계산했다’는 구분합니다. 웹 검색만으로 계산 가능한 시계열이 확보되지 않으면 RSI·베타·유사 조건 승률·백테스트를 계산한 것처럼 쓰지 않도록 지시합니다. 검색 답변의 사실 정확성이나 통계적 우위를 이 검증으로 입증한 것은 아닙니다.
