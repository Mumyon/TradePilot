# 주문 전 ChatGPT 정량 분석 구현·검증

2026-11-09, Flutter iPhone 시뮬레이터와 로컬 FastAPI·PostgreSQL·Toss 시세 환경에서 확인했습니다.

## 적용한 사용자 흐름

차트 → 매수/매도 → 주문 입력 팝업 → 주문 확인 → **‘주문을 확인해 주세요’ 팝업에서 ChatGPT 자동 분석** → 사용자가 최종 모의주문 접수 여부 결정.

- 행동점수, 과매매, 계획 위반, 경고 확인 체크박스, 분석 사용 여부 선택을 주문 확인 화면에서 제거했습니다.
- 뒤로가기는 입력한 주문 가격·수량을 유지합니다.
- 투자 예정 기간(단기/스윙/중장기), 투자 성향(보수적/중립적/공격적)을 선택할 수 있습니다. 기본은 스윙·중립적이며 변경하면 새 주문 점검과 분석을 요청합니다.
- 분석 중·실패·연결 해제·주문 점검 만료·시세 지연 상태에서는 접수 버튼이 비활성화됩니다. 분석의 판단이 ‘관망’이어도 최종 결정은 사용자가 합니다.
- 매수와 매도 모두 분석하며, 매도는 매도·축소 시점으로 해석하도록 지시합니다. AI가 주문을 자동으로 실행하지 않습니다.

## 프롬프트와 분석 자료

사용자가 제공한 정량 애널리스트 프롬프트는 `server/app/prompts/quant_entry_ko.txt`에 보존했습니다. 서버가 실제 수집 자료·지표·누락 자료와 함께 연결된 ChatGPT 모델에 전달합니다. 매도 해석, 최근 체결가와 호가의 구분, 미확보 자료·통계의 생성 금지, 구조화 응답 지침을 추가했습니다.

종목별 최대 최근 365일의 수정 일봉을 페이지 단위로 수집·중복 제거합니다. 당일 미완성 일봉은 지표 계산에서 제외합니다. 최신 체결가와 그 기준 시각, KOSPI 비교 일봉, USD/KRW 환율도 전달합니다. 종목별 상장 기간·제공처 응답에 따라 일봉 수는 달라집니다.

서버가 SMA/EMA 5·20·60·120, RSI14, MACD, ADX14, ATR14, 볼린저 밴드, OBV, 거래량 비율, 기간별 수익률·실현변동성, 경험적 VaR·ES, 베타·상대수익률, 유사조건의 5·10·20거래일 관측 성과를 계산합니다. 가격 후보와 손익비는 ATR 공식의 예시이며 최적값을 의미하지 않습니다.

유사조건 계산은 신호 당일까지의 지표, 다음 날 시가 진입, 기간별 비중복 표본을 사용합니다. 각 방향에 수수료 0.015%와 가정 슬리피지 0.10%를 반영하며 세금은 제외했습니다. 표본 수·분석 구간·낮은 신뢰도를 함께 전달합니다. 수집한 일봉은 같은 KST 날짜 내 재사용합니다.

OpenAI로 보내는 자료는 선택 종목, 주문 방향, 투자 기간·성향과 시장자료입니다. 계좌 식별정보, 잔고, 개인 거래 이력·행동점수·자유입력 메모는 포함하지 않습니다. 현재 연결 방식은 본인 ChatGPT 구독 OAuth이며 해당 구독 한도가 적용됩니다.

## 실제 검증 결과

- 서버 회귀 검사: 55개 통과(정량 지표, 인과성, 일봉 페이지 처리, 자동 분석 요청, 계정 연결, 주문·잔고 포함).
- Flutter 검사: 9개 통과(자동 시작, 정량 결과 표시, 뒤로가기와 입력 유지, 실패·만료·차단 시 접수 금지).
- Flutter 정적 분석: 문제 없음. 변경한 Python 모듈 Ruff 검사 통과.
- 격리된 테스트 DB에서 실제 ChatGPT 요청 성공: 약 48.5초.
- 실제 앱 계정의 iPhone 주문 확인 팝업에서도 자동 요청·결과 표시를 확인: 약 47.6초, 모델 `gpt-6-sol`.
- 삼성전자 일봉 243개(2025-11-10~2026-11-06), 당시 최근 체결가 191,600원과 KOSPI·환율을 사용했습니다. 응답의 최종 판단은 ‘관망’입니다. 모의주문 최종 접수는 하지 않았습니다.
- 긴 정량 보고서의 SSE 스트림 수신 한도를 2MiB로 조정했으며, 완료 이벤트 검증과 크기 제한은 유지합니다. 생성 제한 시간은 150초, 주문 점검 기본 유효기간은 300초입니다. 최종 접수 시 최신 시세와 자금·수량을 다시 검증합니다.

실제 앱의 전체 응답과 서버 계산값은 [삼성전자 분석 응답](QUANT_SAMSUNG_RESPONSE_2026-11-09.md)에 저장했습니다. 생성 시점의 자료이며 이후 시세에는 그대로 적용할 수 없습니다.

## 자료의 범위와 남은 한계

업종별 수익률, 예정 실적발표·기업 일정, 금리 이력·변동성지수, 확정 RSI 다이버전스는 아직 확보하지 못했습니다. 모델에 누락을 명시하고 확인했다고 쓰지 못하도록 지시합니다. 이번 실제 유사조건 표본은 각각 5·3·1건으로, 미래 승률이나 기대수익의 검증 결과가 아닙니다. 분석은 일봉 지표와 최신 체결가를 결합하며 장중 체결가를 완성된 일봉으로 취급하지 않습니다. 휴장일 외 일봉 결측과 기업행사별 수정주가의 교차 검증은 미완료입니다.

## 재개할 때

프로젝트 루트에서 `./tool/start_market_paper.sh --provider toss`로 서버를 시작합니다. 실행 중인 Flutter에는 핫 리스타트가 적용되어 있습니다. 차트에서 종목을 선택하고 매수/매도 주문 확인을 누르면 자동 분석합니다. 연결 정보가 없거나 구독 한도가 소진된 경우 팝업의 ChatGPT 연결 안내 또는 오류 메시지를 확인합니다.
