# ChatGPT Plus · 개인 로컬 AI 복기 연결

## 현재 구현 범위

모의투자 연구 모드에서 ON/OFF 한 쌍을 모두 종료한 뒤 선택적으로 AI 복기를 생성합니다. 서버가 계산한 행동 집계 사실을 OpenAI에 전달하고, 사실에 연결된 해설과 돌아볼 질문을 받습니다. 일반 계좌의 주문 전 AI 설명·주가 예측 모델 교체는 이번 범위에 포함하지 않습니다.

공식 Sign in with ChatGPT의 오픈소스/로컬 실행 경로를 사용합니다. 현재 미리보기 및 계정별 접근 조건이 적용될 수 있으며, 실제 계정에서 로그인·구독 사용 권한이 승인되어야 사용할 수 있습니다. Plus 계정의 한도·크레딧 사용 설정은 ChatGPT 설정에서 확인하세요. 일반 API 키, 다른 앱의 토큰, Codex 인증 파일을 사용하거나 유료 API로 자동 전환하지 않습니다. 원격 공유 서버로 공개하는 방식은 이 개인 로컬 연결과 별도로 검토해야 합니다.

## 지금 연결하기

로컬 서버는 현재 18081에서 최신 코드로 실행 중입니다. 프로젝트 터미널에서 다음 명령을 실행하세요.

```sh
cd /Users/mumyon/Documents/TradePilot
./tool/connect_chatgpt.sh
```

1. **TradePilot 앱에 가입한 이메일**과 **앱 비밀번호**를 터미널에서 입력합니다. 비밀번호는 화면에 표시되지 않습니다.
2. 브라우저에서 열린 TradePilot 페이지의 **Continue with ChatGPT**를 선택합니다.
3. OpenAI의 공식 화면에서 본인 Plus 계정으로 로그인하고 구독 사용 권한에 동의합니다. OpenAI 비밀번호를 TradePilot 터미널에 입력하는 과정은 없습니다.
4. 브라우저 응답을 받은 뒤 터미널에 표시되는 **계정에서 사용할 수 있는 모델 목록**에서 번호를 선택합니다. 등록된 모델을 임의로 추측하지 않습니다.
5. 연결 완료가 표시되면 앱에서 AI 연결 상태를 새로고침합니다.

연결은 3분 안에 브라우저 인증을 완료해야 합니다. 취소하거나 실패하면 기존 연결 정보는 교체하지 않습니다. 실제 Plus 로그인·추론 성공 여부는 사용자 인증 이후에 확인할 수 있습니다.

이후 앱 사용 순서:

**모의투자 → 사례 실험 → 첫 실험 종료 → 같은 조건·반대 Pilot → 두 번째 실험 종료 → 결과 하단 ChatGPT AI 복기 → AI 연결 상태 새로고침 → AI 복기 생성 → 동의하고 생성**

예전 규칙 스냅샷이 없는 실험은 새 쌍으로 시작하세요. 첫 실험만 끝난 시점에는 두 번째 조건에 피드백이 영향을 주지 않도록 복기 생성을 차단합니다. 두 결과 각각에 대해 복기를 생성할 수 있습니다. 실제 과거 사례와 합성 연습 모두 가능하지만 합성 자료가 논문 실데이터로 바뀌지는 않습니다.

## 다음에 다시 실행할 때

별도 터미널에서 서버와 앱을 실행합니다. 서버가 이미 켜져 있으면 중복 실행하지 마세요.

```sh
cd /Users/mumyon/Documents/TradePilot
./tool/start_demo_server.sh
```

```sh
cd /Users/mumyon/Documents/TradePilot
./tool/start_ios_demo.sh 415A659E-9A09-4C35-BABB-2FA140F9BDA8
```

개인 시연 서버에서는 AI 복기가 기본 활성화되어 있습니다. 외부 요청은 본인 연결과 생성 동의가 있을 때만 발생합니다. 기능을 끄려면 서버 시작 시 `AI_REVIEW_ENABLED=false`를 지정합니다. 일반 서버의 기본값은 비활성화이며 `AI_REVIEW_ENABLED=true`로 명시해야 합니다. 로컬 제한은 기본 활성화되어 있고 개인 시연 서버에서는 강제로 유지합니다.

의존성 환경을 다시 설치해야 할 때만 server 폴더에서 실행합니다.

```sh
uv sync --frozen --extra chatgpt-review --extra model-comparison --group postgres-test
```

현재 설치는 완료되어 있습니다. 모델 비교 extra는 기존 트리 모델 비교를 위한 것이며 AI 복기에 필수는 아닙니다.

```sh
cd /Users/mumyon/Documents/TradePilot
./tool/connect_chatgpt.sh --email APP_LOGIN_EMAIL --disconnect
```

앱 계정 확인 후 OpenAI의 공식 해제 경로를 호출하고 로컬 토큰을 제거합니다. 네트워크 오류로 원격 해제가 확인되지 않으면 이를 안내합니다. ChatGPT 설정에서도 해당 앱의 사용량과 권한을 확인할 수 있습니다. 다른 ChatGPT 앱이나 Codex의 로그인 정보에는 접근하지 않습니다.

## 데이터와 연구 기록

외부 전송은 다음 집계로 제한합니다.

- 접수·체결·명시적 보류 횟수
- 평가 가능한 계획 준수·미등록·판단 불가 건수
- 유형별 사후 탐지·계획 예외·판단 불가 건수
- 실제 경고 표시와 표시 후 보류·진행 횟수

종목명·날짜·사건명·가격 시계열·계좌정보·사용자 식별자·자유서술 이유·다른 조건의 기록·미래 봉은 보내지 않습니다. 외부 모델이 과거 유명 사건의 결말을 알고 해설하는 정보 누출을 줄이기 위해 원시 장세 정보를 제외했습니다.

기존 위험 규칙이 사실을 계산하고, 생성형 AI는 그 사실에 연결된 해설만 제공합니다. 서버는 응답 형식·참조 사실 ID·중복·필드 길이·새 숫자/URL 생성을 검사합니다. 의미 전체가 자동 검증된다는 뜻은 아니므로 화면에서 서버 집계와 AI 해설을 분리하고 해석 한계를 표시합니다.

입력·SHA-256, 프롬프트 원문/버전, 출력 스키마, 요청 모델·응답 모델·응답 ID, 사용량, 처리 시간과 검증된 결과를 보존합니다. 연구 JSON 내보내기의 `ai_review`에 포함되며 기존 실험 상태·비교 키·예측·CSV 계산은 변경하지 않습니다. 이 기록은 생성 결과를 증명하며 실제 화면을 읽었다는 증명이나 뇌동매매 예방 효과의 증거는 아닙니다. API 모델의 내부 가중치를 고정했다고 주장할 수 없으므로 실제 생성 응답을 보존·재사용합니다.

## 요청 처리와 오류

- 생성 전 앱에서 외부 전송과 구독 사용 동의를 받습니다. 상태 조회는 새 추론을 요청하지 않습니다.
- 요청은 DB 작업으로 저장되고 별도 워커가 처리합니다. 주문 DB 트랜잭션 안에서 OpenAI 응답을 기다리지 않습니다.
- 완료 결과는 재사용하고 중복 요청은 같은 작업을 반환합니다. 실패 시 명시적 재요청만 허용하며 한 실험 최대 2회, 계정당 최근 24시간 5회로 제한합니다.
- 사용 한도·연결 끊김·미완료 스트림·형식 오류·근거 ID 오류 시 성공 결과를 만들지 않습니다. 기존 행동 피드백은 계속 제공됩니다.
- 서버 재시작으로 생성 중 작업이 중단되면 자동 재전송하지 않고 실패 상태로 남겨, 외부 요청이 중복될 가능성을 줄입니다.
- 토큰은 앱 계정별 로컬 보호 파일에 저장합니다. PKCE·state·nonce 및 서명/발급자/대상/만료를 검증하고 갱신을 직렬화합니다. 로그인·갱신 중인 파일에는 동시 접근하지 않습니다.

## 검증 결과와 실제 연결 상태

서버 전체 215개, Flutter 전체 49개, iPhone 17 네이티브 연동 검증 통과. 이후 연결 해제의 원격 실패 시 로컬 정리 테스트를 1개 추가해 관련 인증 테스트 9개를 재검증했습니다(서로 다른 서버 테스트 총 216개). Ruff·포맷·uv 잠금 확인 통과.

네이티브 검증은 임시 PostgreSQL·합성 사례·OpenAI HTTP 응답 대역을 사용했습니다. 공식 요청의 형식과 화면/저장/중복 방지는 검증했으나 **실제 Plus 계정 로그인이나 외부 모델 추론은 아직 실행하지 않았습니다.** 검증 캡처를 논문 참여자 데이터나 실제 모델 성능으로 사용하지 마세요.

- [자동검증 복기 화면](../../client/docs/ai-review/review.png)

기존 시연 DB에 `20261102_ai_reviews` 마이그레이션을 적용했고 사용자·주문·실험·사례 테이블의 기존 행 식별자 해시가 유지됨을 확인했습니다. 일반 서버 18081은 ready, 일반 시연 앱 실행 후 detach, 임시 18080 서버는 종료했습니다.
