# CSV 학습 및 예측 준비

실제 과거 5분봉과 학습·검증·추론 경로가 연결되어 있습니다. 확보 자료와 성능 한계는 프로젝트의 HISTORICAL_DATA_REPORT.md 및 AI_DEVELOPMENT_REPORT_2026-11-02.md를 확인하세요. 합성 테스트 결과를 실제 투자 성능으로 사용하지 않습니다.

## CSV 형식

UTF-8, 종목별 파일 하나, 시간 오름차순, 중복 없음. 아래는 **형식 예시이며 학습 데이터가 아닙니다**.

```csv
opened_at,open_won,high_won,low_won,close_won,volume
2026-10-16T09:00:00+09:00,70000,70200,69900,70100,1200
2026-10-16T09:05:00+09:00,70100,70300,70000,70200,1500
```

- 시간대가 명시된 5분봉 시작 시간. 평일 한국시간 09:00~15:25, 5분 간격.
- 가격은 양의 정수 원화, 거래량은 0 이상 정수. 고가/저가 관계를 검사합니다.
- 지표는 연속 35개 봉부터, 라벨은 이후 12개 봉(1시간)이 모두 있는 경우만 생성합니다. 날짜/누락 간격을 넘겨 계산하지 않습니다.
- 최소 240개 라벨 표본, 분할별 최소 30개, 학습 구간 3개 클래스 모두 필요합니다. 짧은 파일이나 단일 방향 자료는 거절됩니다.
- 휴장일·분할/배당 조정·이상 거래의 정제는 데이터 제공 단계에서 필요합니다. 현 구현은 휴장일 달력과 기업행동 조정을 제공하지 않습니다.

## 학습

프로젝트의 `server` 디렉터리에서 실행합니다. 실제 확보한 파일 경로와 출처 이름을 넣으세요.

```sh
.venv/bin/python -m app.ml.cli train --csv /absolute/path/prices.csv --symbol 005930 --source myprovider --data-kind historical --output models/005930.json
```

외부 데이터를 자동 다운로드하지 않습니다. `synthetic` 자료의 아티팩트는 공개 예측 API에서 차단합니다. `historical` 지정은 사용자의 출처 선언이며, 실제 원본을 자동 인증하지 않습니다.

모델은 설명 가능한 다중 클래스 로지스틱 회귀 베이스라인입니다. 수익률·이동평균 괴리·RSI·MACD·거래량 지표를 사용합니다. 1시간 수익률 +0.5% 초과는 상승, -0.5% 미만은 하락, 나머지는 중립입니다. 최대 확률이 65% 미만이면 판단 보류합니다.

시간순 60/20/20 분할, 경계의 미래 라벨 중첩 제거, 학습 구간만 정규화, 검증 구간 온도 보정, 3회 확장 구간 검증을 적용합니다. 정확도·클래스별 precision/recall·macro F1·혼동행렬·Brier·보정 오차·판단 보류 비율 및 학습 클래스 비중 기준선과 비교합니다. 테스트 구간 F1/Brier 기준선을 통과해야 제공 가능합니다. 테스트를 반복 보며 모델을 선택했다면 새 독립 홀드아웃이 필요합니다.

## 서버에 연결

```sh
.venv/bin/alembic upgrade head
.venv/bin/python -m app.ml.cli import-candles --csv /absolute/path/prices.csv --symbol 005930 --source myprovider --data-kind historical
```

`server/.env`에 서버가 읽을 수 있는 모델 절대 경로를 지정한 뒤 서버를 재시작합니다.

```dotenv
PREDICTION_MODEL_PATH=/absolute/path/TradePilot/server/models/005930.json
ORDERS_HALTED=false
```

현재 모델 설정은 한 종목/한 출처 파일입니다. 학습 마지막 시점보다 이후이고, 동일 출처의 신선한 완성 5분봉이 연속 35개 있어야 예측합니다. 과거 CSV만 넣으면 현재 예측은 **시세 지연으로 대기**합니다. 이후 실시간 데이터 어댑터에서 완성 봉을 같은 출처로 공급해야 합니다. 정규장 종료 1시간 이내 및 장외에는 새 예측을 보류합니다. 증권사 어댑터는 아직 연결하지 않았습니다.

예측은 종목/봉/모델 버전별로 저장합니다. 정확히 1시간 뒤 완성 봉이 들어오면 워커 또는 매매일지 조회에서 실제 방향을 기록합니다. 해당 봉이 없으면 결과 대기 상태를 유지합니다. 예측 결과는 실제 매매 손익과 별개입니다.

JSON 아티팩트에는 모델 파라미터·CSV 해시·출처·기간·검증 보고서를 포함합니다. 모델 파일은 신뢰하는 로컬 파일만 사용하세요. 실데이터/모델 파일은 저장소에 커밋하지 않는 것을 권장합니다.

## 오프라인 후보 비교

서버 디렉터리에서 비교용 선택 의존성을 설치합니다. 일반 API 서버에는 이 extra가 필요하지 않습니다.

```sh
uv sync --frozen --extra model-comparison
```

```sh
.venv/bin/python -m app.ml.experiment \
  --csv output/ai-review-2026-11-02/observed-005930.csv \
  --source yahoo-finance-5m --data-kind historical \
  --output output/ai-tree-comparison/comparison.json
```

기본 후보는 softmax, balanced-softmax, HistGradientBoosting, CatBoost입니다. 동일 지표와
시간순 60/20/20 분할 및 라벨 중첩 제거를 사용합니다. 트리는 고정된 작은 모델로 CPU 1스레드에서
학습하며 내부 무작위 검증 분할·조기종료를 사용하지 않습니다. 각 후보의 확률 온도 보정은 검증
구간에서만 수행합니다. 후보 선택은 검증 Macro-F1, 동점이면 Brier 순이며 시험 결과로 재선택하지
않습니다. 모든 후보의 시험 결과는 비교 보고용으로 남깁니다.

선택 모델의 연구 기준은 F1의 기준선 대비 엄격 개선, Brier 비악화, 상승·하락 클래스 표본과
재현율 존재입니다. schema 2에서는 고정된 65% 기준의 실제 상승/하락 예측이 적어도 1개 있는지도
검사합니다. 이는 최소 탐색 기준이며 충분한 예측력의 인증은 아닙니다. JSON에 항목별 통과/탈락
이유, 보류율, 판단한 표본 수·정확도, 패키지 버전과 데이터 해시를 기록합니다.

실제 과거 데이터로 선언되고 위 기준을 모두 통과한 **검증 선택 모델**만
`app_connection_candidate`에 기록합니다. 선택 모델이 실패하면 다른 모델의 시험 결과가 좋아도
대체 후보로 승격하지 않습니다. 합성·출처 미확인 데이터는 연결 후보가 될 수 없습니다.
과거에 살펴본 자료의 재분석은 독립 시험이 아니므로, 후보 선정 후에도 추가 독립 평가와
추론 어댑터가 필요합니다. `deployment_approved`는 false이며 앱 모델을 자동 교체하지 않습니다.

트리 라이브러리 없이 기존 모델만 실행하려면 다음 인자를 추가합니다.

```sh
--models softmax balanced-softmax
```

보고서는 새 파일 경로로만 저장됩니다. 같은 경로로 재실행하면 기존 결과를 보존하고 거절합니다.
