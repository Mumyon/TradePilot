# 랜덤 포레스트와 볼린저밴드 하단 조건 비교

2026-09-01~2026-11-13 토스 5분봉의 기존 평가 구간을 재사용한 탐색 실험이다. 국내 연구의 하단 접촉 아이디어를 TradePilot의 고정 1시간 ±0.5% 정답에 적용했다. 원 논문의 거래대금 봉과 삼중 배리어 정답을 재현한 실험은 아니다. [국내 논문](https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE11840361)

종목별로 학습 26거래일, 확률 보정 8거래일, 기존 모델 선택 위치에 맞춘 미사용 8거래일, 테스트 10거래일의 시간순 창을 사용했다. 테스트 구간은 겹치지 않는 5개다. 두 방식은 같은 모델과 확률을 사용한다. 필터 버전은 직전 20개 완료 봉의 종가 평균에서 표준편차 2배를 뺀 값에 현재 완료 봉의 저가가 닿았을 때만 평가한다. 기본 성능의 기준 모델도 각 방식과 같은 표본에서 비교했다. 방향 신호는 확률 65% 이상이며 1시간 내 겹치는 신호는 제외했다.

접촉 필터는 후보 시점을 줄였지만 방향 적중을 개선하지 않았다. 삼성전자에서 두 방식 모두 방향 신호 20건 기준에 미달했고, SK하이닉스는 방향 신호가 없었다. 이 비교로 랜덤 포레스트나 접촉 조건을 앱에 배포할 근거는 확보되지 않았다.
