03. 과거 장세 실험 · 처음 따라 하기

  1. 모의투자를 열고 실제 국내 5분봉 사례를 선택합니다. 기본 사례는 삼성전자 2026-07-29, 08-21, 10-13, 10-15입니다.
  2. 자료 출처, 누락 안내, AI 상태를 확인하고 실험 시작을 누릅니다.
  3. Pilot 행동 피드백 ON/OFF를 선택합니다. 필요하면 사전 계획 등록을 켜서 매수/매도 방향, 가격 범위, 누적 금액, 손절가와 분할 여부를 입력하고 시작합니다. 시작 후 조건과 계획은 고정됩니다.
  4. 가상 현금 1,000만 원·보유 0주로 출발합니다. 다음 5분봉을 눌러 시장을 진행합니다. 현재까지 공개된 시세만 볼 수 있습니다.
  5. 매수 또는 매도 선택 → 수량 입력 → 지정가 입력(또는 현재가 입력) → 주문 점검을 누릅니다.
  6. 점검 결과와 주문 요약을 읽고 접수하거나 주문 보류를 선택합니다. 경고가 요구하는 이유·확인을 완료해야 접수할 수 있습니다.
  7. 접수 후 다음 5분봉을 눌러 체결 여부를 확인합니다. 대기 주문은 주문 취소로 취소할 수 있습니다.
  8. 실험을 종료한 뒤 연구 관찰 결과를 확인합니다. 같은 계정으로 다시 접속하면 진행 중 실험을 이어갈 수 있습니다.
접수 ≠ 체결. 다음 연속 관측 봉의 시가가 매수 지정가 이하 또는 매도 지정가 이상이면 전량 체결됩니다. 조건 미충족은 대기하며, 결측·장간 단절에서는 미체결 주문이 취소됩니다. 종료 시 남은 주문도 자동 취소됩니다.

재생 계좌는 일반 모의계좌와 독립적입니다. 수수료는 편도 0.015%이며 원 단위 올림입니다. 세금·슬리피지·부분 체결·호가 대기는 반영하지 않습니다.

04. Pilot과 AI 읽는 법

Pilot · 행동 피드백

급등 추격, 손실 중 급락 매도, 연속 손실 후 재매수, 과매매, 사전 계획 위반 등을 점검합니다.

ON에서는 경고와 판단 보조를 표시합니다. 점수 30 이상은 이유·확인, 60 이상은 추가 확인이 필요합니다. OFF의 경고 대상 기록은 실험 종료 후 연구 자료에 공개됩니다.

AI · 방향 정보

상승·보합·하락 확률 또는 예측 보류 이유를 확인합니다. AI 정보는 ON/OFF 양쪽에 동일하게 제공됩니다.

학습·검증 미달, 연속 35봉 부족, 최고 확률 65% 미만, 종료까지 1시간 미만 등의 조건에서는 방향 판단을 보류할 수 있습니다.

재생 실험에서는 Pilot OFF에도 주문당 100만 원, 일일 순실현손실 100만 원, 같은 방향 300초 쿨다운, 현금·수량 제한을 적용합니다. 이 설정은 고정이며 일반 계좌 거래 설정과 별개입니다.

7월 29일 사례는 학습 표본 부족, 8월 21일은 검증 미달로 예측이 제공되지 않습니다. 10월 13일·15일도 조건에 따라 보류됩니다. 검증 기준 통과는 실용 예측력이나 수익성을 입증하는 뜻이 아닙니다.

05. ON/OFF 비교와 결과 저장

  1. 첫 실험을 완료하고 같은 조건 · 반대 Pilot을 누릅니다.
  2. 같은 사례·모델·초기 자금·위험 설정·계획으로 반대 조건의 실험을 진행합니다. 계좌와 가상 시계는 처음부터 시작합니다.
  3. 완료된 실험 쌍에서 계획 준수, 경고 대상 점검·접수, 경고 후 보류, 판단 시간, 수익률·최대 낙폭을 비교합니다.
  4. 연구 CSV 복사를 누른 뒤 텍스트 편집기에 붙여 넣어 UTF-8 .csv 파일로 저장합니다.
  5. 원본 JSON 복사도 실행해 .json 파일로 함께 보존합니다. 버튼은 파일 다운로드가 아닌 클립보드 복사입니다.

CSV는 점검별 한 행이며 무거래 실험은 헤더만 있을 수 있습니다. JSON에는 세션 결과, 시세, 모델, 정책과 계좌 이력이 포함됩니다. 계획 미등록·평가 불가는 준수율 산정에서 제외합니다.

같은 장세를 두 번 경험하면 학습·순서 효과가 생깁니다. 연구에서는 ON→OFF와 OFF→ON 순서를 균형 있게 배정하세요. 반복 점검을 서로 독립된 참가자처럼 계산하거나 수익률만으로 판단 개선을 결론 내리지 않습니다.

06. 일반 모의계좌 · 수동 주문과 일지

  1. 관심종목에서 삼성전자 또는 SK하이닉스를 선택하고 차트·시세 기준 시각을 확인합니다.
  2. 모의투자 → 기존 모의계좌 · 전략 → 매매 계획에서 종목·방향·가격 범위·최대 금액을 저장합니다.
  3. 차트의 매수 / 매도에서 수량과 지정가를 입력하고 계획 선택 → 점검 → 최종 요약 확인 → 접수 순서로 진행합니다.
  4. 서버의 다음 시세가 조건을 만족하면 체결됩니다. 미체결은 계좌 관리의 주문·체결에서 취소합니다.
  5. 매매일지 → 전체 보기에서 접수·체결 상태와 당시 판단을 펼쳐 보고 복기 메모를 작성합니다.

일반 계좌의 Pilot OFF 또는 낮음 상태에서는 거래 이유가 선택 입력입니다. 주의 이상은 3자 이상 이유와 경고 확인, 높음은 추가 확인이 필요합니다. 위험한도는 Pilot OFF에도 유지됩니다. 일반 계좌 한도·쿨다운은 거래 설정에서 확인합니다.

07. 전략과 백테스트

  1. 모의투자 → 기존 모의계좌 · 전략 → 백테스트로 이동합니다.
  2. 전략명·종목 코드·단기/장기 이동평균 기간을 입력하고 새 전략 저장을 누릅니다. 처음에는 삼성전자 005930, 5/20 기간을 사용할 수 있습니다.
  3. 저장된 전략을 선택하고 데이터·기간·초기 자금·비용을 확인한 뒤 백테스트 실행을 누릅니다. source demo는 합성 자료입니다.
  4. 수익률, 최대 낙폭, 완료 거래 수, 승률, 실현·미실현 손익, 수수료와 거래 내역을 확인합니다. 저장 결과를 다시 열 수 있습니다.

입력만 바꾸면 저장 전략은 바뀌지 않습니다. 수정 버튼으로 저장한 뒤 실행하세요. 전략의 활성은 실행 허용 상태이며 자동 주문 시작은 별도입니다. 백테스트는 일반 계좌 잔고를 변경하지 않습니다.

완료 봉의 종가로 신호를 계산하고 다음 연속 봉의 시가로 체결합니다. 기본 편도 수수료 2bp(0.02%), 슬리피지 5bp(0.05%)를 사용합니다. 마지막 보유는 강제 매도하지 않고 평가하며 미청산 포지션은 승률에서 제외합니다.

08. 모의 자동매매

  1. 백테스트 화면에서 모의 자동매매 관리를 엽니다.
  2. 저장 전략과 매수 예산을 선택합니다. 최초 예산 기본값은 50만 원이며 일반 계좌 1회 주문한도 이하여야 합니다.
  3. 해당 종목의 보유·미체결이 없는지 확인하고 선택 전략 시작 / 재개 → 모의 실행 시작을 누릅니다.
  4. 실행 카드와 신호·주문 이력에서 주문 여부·건너뛴 이유를 확인합니다. 새 완료 5분봉마다 평가하고 화면은 5초마다 갱신됩니다.
  5. 끝낼 때 중지 · 미체결 취소를 누릅니다. 체결된 주식은 유지되므로 필요하면 수동 매도합니다.

앱 종료·로그아웃만으로 자동매매는 멈추지 않습니다. 서버가 켜져 있으면 계속 실행하며 서버 재시작 후에도 활성 상태가 보존됩니다. 종료 전에 관리 화면에서 중지하세요.

현재 합성 시세의 삼성전자·SK하이닉스 이동평균 전략만 지원합니다. 시작 시 전략·예산은 고정됩니다. 행동 경고가 사용자 확인을 요구하면 자동 승인하지 않고 건너뜁니다. 같은 종목 수동 거래가 감지되면 실행이 자동 중지됩니다.

09. CSV 업로드와 나만의 사례

  1. 모의투자 → CSV 관리에서 파일을 선택합니다.
  2. 이름·종목 코드·출처·자료 종류를 입력합니다. 실제 과거 자료와 합성·테스트 자료를 구분합니다.
  3. 등록 전 검증으로 봉 수·기간·연속 봉·단절을 확인하고 검증한 데이터 저장을 누릅니다.
  4. 백테스트용은 백테스트에서 사용을 선택하고 동일 종목 전략으로 실행합니다.
  5. 재생용은 실험 화면의 CSV로 사례 등록에서 데이터·사건 분류·첫 공개 봉 시작 시각을 입력합니다. 해당 시각의 행이 CSV 안에 있어야 합니다.
  6. 필요하면 AI 학습 / 검증을 실행하고 상태를 확인한 뒤 실험을 시작합니다. 첫 실험 시작 후에는 사례 모델을 교체할 수 없습니다.

필수 CSV 형식

opened_at,open_won,high_won,low_won,close_won,volume
2026-10-16T09:00:00+09:00,70000,70100,69900,70025,1000

UTF-8(BOM 허용), 최대 3MB·20,000행, 사용자당 50개입니다. 시간대가 있는 완료 5분봉 시작 시각을 오름차순으로 넣습니다. 평일 KST 09:00~15:25, 중복 없는 시각, 양의 정수 가격, 0 이상 정수 거래량이 필요합니다.

AI 학습에는 사건 이전 여러 거래일을 함께 준비하세요. 최소 240개 라벨 표본과 세 클래스가 필요하며 하루 자료만으로는 부족할 수 있습니다. CSV 등록 자체는 현재 시세·자동매매·공용 AI 모델을 바꾸지 않습니다.

시뮬레이터 파일 선택기는 Mac 프로젝트 폴더를 자동으로 보여주지 않습니다. iPhone 파일 앱이 접근할 수 있는 위치에 파일을 준비하세요. 예제 server/examples/synthetic_5m.csv는 실제 주가가 아닌 합성 자료입니다.

10. 자주 막히는 상황

상황확인할 내용
서버 연결 실패서버 터미널이 실행 중인지, 18081 서버 준비 후 앱을 켰는지 확인합니다.
로그인 화면으로 돌아옴토큰 만료 또는 다른 서버 계정일 수 있습니다. 현재 시연 DB에서 가입한 계정으로 로그인합니다.
새 기능이 안 보임서버와 앱을 최신 코드로 다시 실행합니다. 저장형 실험은 DEMO_MODE=false 서버 연결 모드가 필요합니다.
AI가 예측 보류보류 사유를 확인합니다. 모델 검증·봉 수·결측·확률·남은 시간이 조건을 만족하지 않을 수 있습니다.
주문 접수 후 잔고가 그대로접수와 체결은 다릅니다. 재생은 다음 봉 진행, 일반 계좌는 다음 시세와 지정가 조건 충족을 기다립니다.
재주문 제한같은 종목·방향 쿨다운, 한도, 예약 현금·수량, 일일 손실한도를 확인합니다.
통신 오류로 결과 불명재생 화면의 동일 요청 재시도 또는 서버 상태 다시 읽기로 상태를 확인합니다.
자동매매에 주문이 없음신호·주문 이력의 대기·건너뛴 이유를 확인합니다. 새 완료 봉이나 충분한 연속 자료가 필요할 수 있습니다.
실제 사례에서 급등 경고가 안 나옴가격 변화가 규칙 임계값을 넘지 않으면 정상입니다. 선택 사항인 합성 기능테스트로 경고 흐름을 연습할 수 있습니다.

  • 과거 재생: 기본 4개 사례는 프로젝트에 보존한 Yahoo Finance 실제 관측 5분봉입니다. 정규장 전체 자료가 아니며 누락된 구간을 보간하지 않습니다.
  • 2020·2024 사건: 실제 5분봉 확보 대기입니다. 현재 제공되는 2026년 사례와 구분합니다.
